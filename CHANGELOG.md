# Changelog

All notable changes to Sourcebound are documented here.

## 0.2.0 - 2026-09-03

- Added asynchronous research jobs with explicit lifecycle states and cancellation.
- Added per-run and per-provider telemetry snapshots.
- Added optional evidence-only semantic verification with calibrated verdicts.
- Expanded the deterministic benchmark across multiple research-risk domains.
- Added a live, keyless Wikipedia and OpenAlex run to the portfolio case study.
- Added package metadata, linting, and stronger CI release gates.

## 0.1.0 - 2026-09-01

- Released the citation-grounded multi-source agent, deterministic benchmark,
  FastAPI report adapter, and inspectable portfolio trace.
